# Cry-FPS

A player-controlled movable character using C++ in CRYENGINE 5.7 LTS.

## Features

- WASD key movement
- Mouse camera movement and axis rotation
- Space key jump

## Installation & Build

Before running the project, you must first generate the Visual Studio solution from the CRYENGINE Project Manager.

### Steps

1. Open the CRYENGINE Project Manager.
2. Select the project and click **Generate Solution**.
3. Open the generated `.sln` file in Visual Studio 2022.
4. Build/Rebuild the project from Visual Studio 2022.
5. Launch the project through CRYENGINE or directly from Visual Studio.

## Requirements

- CRYENGINE 5.7 LTS
- Visual Studio 2022
- C++ Development Tools
